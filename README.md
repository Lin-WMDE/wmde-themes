# wmde-themes

Тема WMDE: все дефолты, из которых складывается облик рабочего стола.

Тема регламентирует внешний вид целиком - цвет, геометрию, текст, панель, док, обои. Пакет
обязательный, `wmde-desktop` держит его в зависимостях. Без него стек падает на умолчания,
скомпилированные в libcosmic, а они апстримные и уезжают при каждом мерже.

## Зачем отдельный пакет

Чистая установка и новый пользователь должны увидеть WMDE **до того, как выполнится хоть
одна строчка кода**. `cosmic-config` читает `/usr/share/wmde/<config-id>/v<N>/<key>` как
системный дефолт всякий раз, когда у пользователя своего значения нет. Этот пакет и есть
такой слепок.

## Что внутри

| Конфиг | Что задаёт |
|---|---|
| `fun.wmde.Theme.Dark`, `.Light` | Палитры целиком: цвета, состояния, радиусы, отступы |
| `fun.wmde.Theme.Dark.Builder`, `.Light.Builder` | Исходные параметры деривации палитр |
| `fun.wmde.Theme.Mode` | На какой палитре стартовать, автопереключение |
| `fun.wmde.Tk` | Шрифты интерфейса и моноширинный, имя иконочной темы, кнопки заголовка, плотность, применение темы к чужим тулкитам |
| `fun.wmde.Panel.Panel`, `fun.wmde.Panel` | Геометрия панели: размер, положение, радиус, прозрачность, состав |
| `fun.wmde.AppList` | Закреплённое в доке |
| `fun.wmde.Background` | Обои по умолчанию |
| `fun.wmde.AppletTime` | Часы: 24-часовой формат, неделя с понедельника (`first_day_of_week` = 0) |

Обои названы путём, а сам файл ставит `wmde-bg`. Тема указывает, что показывать, а не несёт
изображение.

## Заставка загрузки

Тема Plymouth `wmde` (`plymouth/wmde/`, ставится в `/usr/share/plymouth/themes/wmde/`), модуль
`two-step`, как у темы `bgrt` из Plymouth. Как при загрузке Windows: на чёрном фоне логотип
производителя из прошивки (ACPI BGRT), под ним спиннер из пяти точек. Где в прошивке логотипа
нет (VM, старые платы), `two-step` показывает `bgrt-fallback.png` - логотип WMDE. Включает
заставку дистрибутив: пакет `plymouth`, хук `plymouth` в initramfs, `splash` в параметрах ядра,
`Theme=wmde` в `/etc/plymouth/plymouthd.conf`; пакет темы держит `plymouth` только в
`optdepends`.

| Файл | Откуда |
|---|---|
| `wmde.plymouth` | раскладка `bgrt.plymouth`, шрифт Noto Sans, подписи по-украински |
| `throbber-0001..0060.png` | спиннер, рисует `plymouth/render.py` |
| `bgrt-fallback.png` | `rsvg-convert -w 160 -h 160` из `wmde-settings/resources/wmde-logo.svg` |
| `entry`, `bullet`, `lock`, `capslock`, `keyboard`, `keymap-render` | из темы `spinner` Plymouth 26.134, GPL-2.0-or-later: поле пароля LUKS и индикаторы раскладки |

Картинки закоммичены, сборка их не рисует. Перерисовать спиннер - `python3 plymouth/render.py`.

## Правка

Часть данных **генерируется и руками не правится**: палитры, режим и обои перезаписываются
целиком при следующем запуске генератора.

```
tools/bake-theme.sh
```

Скрипт собирает `tools/wmde-theme-gen` из исходника, печёт во временный каталог и
синхронизирует сюда. Собирать генератор отдельно и запускать из `target/` нельзя: стухший
бинарь молча печёт старые значения.

Остальное - панель, док, `fun.wmde.Tk`, часы - статические данные, они правятся здесь напрямую.

## Свои темы

Отдельными пакетами. Этот пакет владеет системным дефолтом, и второй пакет, положивший те же
пути, столкнётся с ним по файлам.

Правила и значения - `.doc/appearance/` в корне проекта.
